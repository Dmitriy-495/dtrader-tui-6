# dtrader-tui-6

Терминальный клиент dtrader-6. Читает данные из `ws-server` (см.
`github.com/Dmitriy-495/dtrader-6`) и отображает их в реальном времени.

## Статус: MVP, шаг 2 из N — одна вкладка символа (bubbletea)

Проект начат с нуля 2026-08-17 (предыдущая версия локально накопила
слишком много правок разными руками, решено переписать заново —
см. история чата/CHECKPOINT.md dtrader-6, раздел 16).

**Шаг 1 (связность) подтверждён на проде** 2026-08-17 23:33 MSK —
живые данные с msk по всем каналам (`trades`, `orderbook`,
`indicators`, `system` — включая `symbols`/`positions`).

Сейчас реализовано и проверено:
- `internal/config` — загрузка `.env` (`WS_SERVER_URL`, `WS_API_KEY`).
- `internal/ws` — клиент ws-server: подключение с авторизацией
  (`X-API-Key`), чтение сообщений `{channel, symbol, data}`,
  автопереподключение с задержкой 3s при разрыве. Проверено на
  проде вживую, включая реальный обрыв соединения и реконнект.
- `internal/indicators` — типы канала `indicators` (T/V/P), сняты
  с реального прод-ответа, не из документации.
- `internal/tui` — bubbletea-модель ОДНОЙ вкладки символа: таблица
  T/V/P (строки=ТФ, колонки=T/V/P — решение из чата), pressure
  строкой снизу, статус соединения, цвета по разделу 11 CHECKPOINT.md.
  Юнит-тесты (`go test ./...`) на реальном JSON с прода, включая
  негативные случаи (битый JSON, чужой канал/символ).
- `cmd/main.go` — запускает bubbletea для символа `BTC_USDT`
  (захардкожен временно, `symbolMVP` — заменится автовкладками на
  следующем шаге).

Ещё не реализовано: главный экран со всеми символами, автовкладки
по `symbols` из `system`-канала, переключение Tab/Ctrl+1..N,
header со SERV/EXCH статусами (раздел 11).

## Запуск

```bash
cp .env.example .env
# заполнить WS_SERVER_URL (адрес msk или sgp) и WS_API_KEY

go build -o dtrader-tui-6 ./cmd
./dtrader-tui-6
```

Либо взять готовый бинарник из `dist/` (`dtrader-tui-6-linux-amd64`
или `dtrader-tui-6-darwin-arm64`) — `.env` рядом обязателен в любом
случае (см. `internal/config`, ищет `.env` в текущей директории
запуска).

Ожидаемый результат: рамка с именем символа, статусом соединения,
таблицей T/V/P по 1m/8m/24m, строкой pressure снизу. `q` или
`Ctrl+C` — выход.
